# Data Format

> **Version 0.1.0**

## 1. IQ-TREE Output Files

CF-Panel parses 5 types of files generated by IQ-TREE `--gcf` / `--scf` / `--scfl`:

### 1.1 `gcf.cf.stat`

**Format**: Tab-separated, `#`-prefixed lines are comments

**Columns**: 12

| Column | Type | Description |
|--------|------|-------------|
| ID | int | Branch ID (corresponds to label in cf.branch) |
| gCF | float | Gene concordance factor (percentage) |
| gCF_N | float | Number of concordant gene trees |
| gDF1 | float | First discordance factor (percentage) |
| gDF1_N | float | Number of first discordance gene trees |
| gDF2 | float | Second discordance factor (percentage) |
| gDF2_N | float | Number of second discordance gene trees |
| gDFP | float | All-other discordance factor (percentage) |
| gDFP_N | float | Number of all-other discordance gene trees |
| gN | int | Total number of gene trees |
| Label | string | Quartet annotation label |
| Length | float | Branch length (subs/site) |

**Label column format**:
```
'[q1=0.8398;q2=0.0857;q3=0.0744;f1=296.48;f2=30.25;f3=26.27;pp1=1.0;pp2=0.0;pp3=0.0;QC=721240;EN=353.0]'/51.5
```

- Square brackets contain quartet annotations:
  - `q1/q2/q3`: Quartet frequencies (0-1)
  - `f1/f2/f3`: Quartet counts
  - `pp1/pp2/pp3`: Posterior probabilities
  - `QC`: Total quartet count
  - `EN`: Effective N
- Number after slash is the bootstrap value

### 1.2 `scfl.cf.stat`

**Format**: Tab-separated, `#`-prefixed lines are comments

**Columns**: 10

| Column | Type | Description |
|--------|------|-------------|
| ID | int | Branch ID |
| sCF | float | Site concordance factor (percentage) |
| sCF_N | float | Number of concordant sites |
| sDF1 | float | First discordance factor (percentage) |
| sDF1_N | float | Number of first discordance sites |
| sDF2 | float | Second discordance factor (percentage) |
| sDF2_N | float | Number of second discordance sites |
| sN | int | Number of sampled sites |
| Label | string | Quartet annotation label |
| Length | float | Branch length (subs/site) |

### 1.3 `coalescent_bl.cf.stat`

**Format**: Same as `scfl.cf.stat`

**Difference**: `Length` column is coalescent branch length (not substitution rate length)

### 1.4 `gcf.cf.tree`

**Format**: Newick

**Branch label format**:
```
'[q1=0.9972;q2=7.9e-6;...]'/82.4/99.7
```
- Square brackets contain quartet annotations (same as above)
- After the slash: sCF and gCF values

### 1.5 `gcf.cf.branch`

**Format**: Newick

**Branch label format**:
```
382
```
- Only a branch ID number, serves as the join key with the ID column in cf.stat files

## 2. CF-Panel Output Format

### 2.1 33-Column CF Vectors

CF-Panel builds CF vectors aligned with Lanfear's `concordance_vector.R` output, totaling 33 columns (32 + Label):

```
ID,
gene_psi1, gene_psi2, gene_psi3, gene_psi4,
gene_psi1_N, gene_psi2_N, gene_psi3_N, gene_psi4_N, gene_N,
site_psi1, site_psi2, site_psi3, site_psi4,
site_psi1_N, site_psi2_N, site_psi3_N, site_psi4_N, site_N,
quartet_psi1, quartet_psi2, quartet_psi3, quartet_psi4,
quartet_psi1_N, quartet_psi2_N, quartet_psi3_N, quartet_psi4_N, quartet_N,
quartet_psi1_pp, quartet_psi2_pp, quartet_psi3_pp,
length_subs_per_site, length_coalescent
```

### 2.2 Ψ Value Mapping Rules

#### Gene (from gcf.cf.stat)

| Ψ | Formula | Description |
|-----|---------|-------------|
| Ψ₁ | gCF | Concordance factor |
| Ψ₂ | max(gDF1, gDF2) | Major discordance (larger after sorting) |
| Ψ₃ | min(gDF1, gDF2) | Minor discordance (smaller after sorting) |
| Ψ₄ | gDFP | All-other discordance |

#### Site (from scfl.cf.stat)

| Ψ | Formula | Description |
|-----|---------|-------------|
| Ψ₁ | sCF | Concordance factor |
| Ψ₂ | max(sDF1, sDF2) | Major discordance |
| Ψ₃ | min(sDF1, sDF2) | Minor discordance |
| Ψ₄ | 0 | No fourth component at site level |

#### Quartet (extracted from Label annotation)

| Ψ | Formula | Description |
|-----|---------|-------------|
| Ψ₁ | round(100 × q1, 2) | Concordant quartet frequency (percentage, 0-100) |
| Ψ₂ | round(100 × max(q2, q3), 2) | Major discordance |
| Ψ₃ | round(100 × min(q2, q3), 2) | Minor discordance |
| Ψ₄ | 0 | No fourth component |
| Ψ₁_N | round(f1, 2) | Concordant quartet count |
| Ψ₂_N | round(max(f2, f3), 2) | Major discordance count |
| Ψ₃_N | round(min(f2, f3), 2) | Minor discordance count |
| N | round(EN, 1) | Effective sample size |
| pp₁ | round(pp1, 1) | Concordant posterior probability |
| pp₂ | round(max(pp2, pp3), 1) | Major discordance posterior probability |
| pp₃ | round(min(pp2, pp3), 1) | Minor discordance posterior probability |

### 2.3 Join Logic

1. `scfl.cf.stat` is the primary table (left table in R script's left join)
2. Left join `gcf.cf.stat` by ID column (Gene data)
3. Left join `coalescent_bl.cf.stat` by ID column (coalescent branch lengths)
4. Extract Quartet annotations from the Label column in `scfl.cf.stat`
