# 快速开始

> **版本：0.1.0**

## 5 分钟上手

### 第一步：启动 CF-Panel

启动后您会看到欢迎界面，提供三个入口：

- **加载示例数据** — 内置 bird_400 数据集（363 个分支），无需任何外部文件即可体验全部功能
- **打开 IQ-TREE 输出目录** — 选择包含 CF 分析输出的文件夹
- **选择单个文件** — 手动选择 CF 文件

### 第二步：加载数据

**推荐先点击「加载示例数据」**，这是最快了解 CF-Panel 功能的方式。

如果您有自己的 IQ-TREE 输出：

1. 点击「打开目录」
2. 选择包含以下文件的目录：
   - `gcf.cf.stat` — 基因一致性统计
   - `scfl.cf.stat` — 位点一致性统计
   - `coalescent_bl.cf.stat` — 溯祖分支长度统计
   - `gcf.cf.tree` — 带标签的 Newick 树
   - `gcf.cf.branch` — 带分支 ID 的 Newick 树

### 第三步：三视图联动探索

加载后，主界面显示三个联动视图：

| 视图 | 功能 |
|------|------|
| **🌲 树画布** | 系统发育树 SVG/Canvas 渲染，分支按 CF 值着色 |
| **△ 三元图** | Ψ₁/Ψ₂/Ψ₃ 在等边三角形上的投影散点图 |
| **📋 向量表** | 33 列 CF 向量数据（32 + Label），可排序、搜索、分页 |

**联动操作：**
- 点击树分支 → 三元图对应点高亮、表格滚动到对应行
- 点击三元图散点 → 树分支选中、表格高亮
- 点击表格行 → 树分支和三元图同步选中
- 按 **↑↓** 键在分支间切换

### 第四步：切换 CF 类型

使用顶部工具栏的 **Gene / Site / Quartet** 切换器，在三种一致性因子类型之间切换：

- **🧬 Gene** — gCF（基因一致性因子）
- **🧪 Site** — sCF（位点一致性因子）
- **⬡ Quartet** — qCF（四分组一致性因子）

切换后，所有视图的着色和数据列会自动更新。

### 第五步：查看分支详情

点击任意分支后，右侧面板显示：

- 当前 CF 类型的 Ψ₁/Ψ₂/Ψ₃/Ψ₄ 热力图
- 所有 CF 类型的对比表格
- 分支长度（替换/位点、溯祖）
- 四分组后验概率

### 第六步：导出数据

点击工具栏的「导出 CSV」按钮，将 33 列 CF 向量数据（32 + Label）导出为 CSV 文件，与 Lanfear 的 `concordance_vector.R` 输出格式对齐。

## 视图模式

右上角的视图切换按钮可在四种模式间切换：

| 图标 | 模式 | 说明 |
|------|------|------|
| ⊞ | 全部 | 三视图 + 详情面板 |
| 🌲 | 树 | 仅树画布（全屏） |
| △ | 三元图 | 仅三元图（全屏） |
| 📋 | 表格 | 仅向量表（全屏） |

## 主题与语言

- **主题**：点击 🌙/☀️ 按钮切换暗色/亮色主题
- **语言**：点击 🇬🇧/🇨🇳 按钮切换英文/中文
