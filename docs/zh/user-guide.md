# 用户手册

> **版本：0.1.0**

## 1. 概述

CF-Panel 是一款用于探索 IQ-TREE concordance factor 分析结果的桌面应用。它通过三视图联动的方式，帮助研究者直观地理解基因树与物种树之间的一致性与冲突。

## 2. 界面布局

### 2.1 顶部工具栏

| 功能 | 说明 |
|------|------|
| 📁 打开目录 | 选择 IQ-TREE 输出目录，自动检测 CF 文件 |
| 📄 打开文件 | 手动选择一个或多个 CF 文件 |
| 📊 示例数据 | 加载内置 bird_400 示例数据集 |
| 💾 导出 CSV | 导出 33 列 CF 向量（32 + Label）为 CSV 文件 |
| ✕ 清除 | 清除当前数据，返回欢迎界面 |
| 🧬/🧪/⬡ | 切换 Gene / Site / Quartet CF 类型 |
| ⊞🌲△📋 | 切换视图模式（全部/树/三元图/表格） |
| 🇬🇧/🇨🇳 | 切换语言（英文/中文） |
| 🌙/☀️ | 切换主题（暗色/亮色） |

### 2.2 树画布

树画布以 SVG/Canvas 方式渲染系统发育树（根据分支数量自动选择）：

- **分支着色**：按当前 CF 类型，Ψ₁（一致性）越高越绿，越低越红
- **分支 ID**：内部节点上方显示分支 ID 数字
- **叶标签**：右侧显示分类单元名称
- **交互**：
  - 点击分支：选中并联动其他视图
  - 悬停分支：高亮并联动三元图和表格
  - Ctrl+拖拽：平移画布
  - 滚轮：缩放
  - 右上角控制按钮：放大/缩小/重置视图
- **设置面板**（齿轮图标）：
  - 布局：矩形树、无根树、或环形树
  - 枝长：可选择使用枝长或 cladogram 模式
  - 配色方案：热力图、彩虹、蓝-红、或单色
  - 分支粗细：可调节滑块（0.5-5px）
  - 字体大小：可调节标签字体大小（6-24px）
  - 字体颜色：自定义颜色选择器
  - 显示/隐藏叶子标签和分支 ID
- **搜索框**（左上角）：按名称或 ID 搜索分支，支持正则表达式模式
- **可拖拽面板**：拖拽面板之间的分隔器可调整相对大小

### 2.3 三元图

三元图将每个分支的 Ψ₁/Ψ₂/Ψ₃ 值归一化后投影到等边三角形上：

- **Ψ₁（一致性）**：左下顶点
- **Ψ₂（主要冲突）**：右下顶点
- **Ψ₃（次要冲突）**：顶部顶点
- **交互**：
  - 点击散点：选中分支并联动
  - 悬停散点：显示 tooltip（分支 ID、Ψ 值）
  - 选中分支时其他散点变淡

### 2.4 向量表

向量表显示完整的 CF 向量数据：

- **列动态切换**：根据当前 CF 类型显示不同的列
  - Gene：gΨ₁/gΨ₂/gΨ₃/gΨ₄/gN
  - Site：sΨ₁/sΨ₂/sΨ₃/sΨ₄/sN
  - Quartet：qΨ₁/qΨ₂/qΨ₃/qΨ₄/qN/qpp₁/qpp₂/qpp₃
  - 始终显示：Subs/site、Coalescent
- **功能**：
  - 搜索：在搜索框输入关键词过滤
  - 排序：点击列标题排序
  - 分页：每页 50 条，底部翻页
  - 点击行：选中分支并联动

### 2.5 分支详情面板

选中分支后，右侧显示详情面板：

- **热力图**：当前 CF 类型的 Ψ₁/Ψ₂/Ψ₃/Ψ₄ 值，颜色深浅表示数值大小
- **类型对比表**：Gene / Site / Quartet 三种类型的 Ψ 值并排对比
- **分支长度**：
  - Subs/site：替换/位点（来自 scfl.cf.stat）
  - Coalescent：溯祖长度（来自 coalescent_bl.cf.stat）
- **后验概率**：Quartet 类型的 pp₁/pp₂/pp₃

## 3. 数据加载

### 3.1 自动检测（推荐）

点击「打开目录」，选择 IQ-TREE 输出目录。CF-Panel 会自动检测以下文件：

| 文件名 | 必需 | 说明 |
|--------|------|------|
| `gcf.cf.stat` | 是 | 基因一致性统计（12 列） |
| `scfl.cf.stat` | 是 | 位点一致性统计（10 列） |
| `coalescent_bl.cf.stat` | 否 | 溯祖分支长度统计 |
| `gcf.cf.tree` | 否 | 带标签的 Newick 树 |
| `gcf.cf.branch` | 否 | 带分支 ID 的 Newick 树 |

### 3.2 手动选择文件

点击「打开文件」，选择一个或多个 CF 文件。CF-Panel 会根据文件名自动识别文件类型。

### 3.3 示例数据

点击「示例数据」加载内置的 bird_400 数据集（来自 IQ-TREE recipe，MIT 许可），包含 363 个分支的完整 CF 分析输出。

## 4. CF 类型说明

### 4.1 Gene CF（gCF）

基因一致性因子，来自 `gcf.cf.stat`：

- **Ψ₁ = gCF**：与参考树一致的基因树比例
- **Ψ₂ = max(gDF1, gDF2)**：主要冲突（排序后较大值）
- **Ψ₃ = min(gDF1, gDF2)**：次要冲突（排序后较小值）
- **Ψ₄ = gDFP**：全部其他冲突
- **N = gN**：基因树总数

### 4.2 Site CF（sCF）

位点一致性因子，来自 `scfl.cf.stat`：

- **Ψ₁ = sCF**：与参考树一致的位点比例
- **Ψ₂ = max(sDF1, sDF2)**：主要冲突
- **Ψ₃ = min(sDF1, sDF2)**：次要冲突
- **Ψ₄ = 0**（位点层面不存在第四分量）
- **N = sN**：采样位点数

### 4.3 Quartet CF（qCF）

四分组一致性因子，从 `scfl.cf.stat` 的 Label 列注解中提取：

- **Ψ₁ = 100 × q1**：一致四分组频率
- **Ψ₂ = 100 × max(q2, q3)**：主要冲突
- **Ψ₃ = 100 × min(q2, q3)**：次要冲突
- **Ψ₄ = 0**
- **N = EN**：有效样本量
- **pp₁/pp₂/pp₃**：后验概率

## 5. 导出

点击「导出 CSV」将当前加载的 33 列 CF 向量（32 + Label）导出为 CSV 文件，格式与 Lanfear 的 `concordance_vector.R` 脚本输出对齐。
